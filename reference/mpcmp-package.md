# Mean-parametrized Conway-Maxwell Poisson Regression

A collection of functions for estimation, testing and diagnostic
checking for the mean-parametrized Conway-Maxwell-Poisson (COM-Poisson)
regression model of Huang (2017).

## References

Fung, T., Alwan, A., Wishart, J. and Huang, A. (2019). `mpcmp`:
Mean-parametrized Conway-Maxwell Poisson Regression. R package version
0.2.0.

Huang, A. (2017). Mean-parametrized Conway-Maxwell-Poisson regression
models for dispersed counts. *Statistical Modelling* **17**, 359–380.
