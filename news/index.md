# Changelog

## mpcmp 0.3.9

- Added missing `\value` documentation to Rd files for exported
  functions, methods and datasets that lacked it, per CRAN feedback.
- [`cmplrtest()`](https://thomas-fung.github.io/mpcmp/reference/cmplrtest.md)
  now returns an object of class `"htest"` instead of printing results
  via [`cat()`](https://rdrr.io/r/base/cat.html); the returned object is
  displayed via `print.htest()` and its statistic, degrees of freedom
  and p-value can be extracted directly.
- [`LRTnu()`](https://thomas-fung.github.io/mpcmp/reference/LRTnu.md)
  now returns an object of class `"htest"` instead of printing results
  via [`cat()`](https://rdrr.io/r/base/cat.html); the returned object is
  displayed via `print.htest()` and its statistic, degrees of freedom,
  p-value and log-likelihoods can be extracted directly.
- [`plot.cmp()`](https://thomas-fung.github.io/mpcmp/reference/plot.cmp.md)
  documentation example that was previously commented out is now
  runnable.

## mpcmp 0.3.0

- Updated
  [`glm.cmp()`](https://thomas-fung.github.io/mpcmp/reference/glm.cmp.md)
  to allow varying dispersion. You can now link the dispersion
  parameters to some covariates via a log-link.
- Most calculations are now performed inside
  [`fit_glm_cmp_const_nu()`](https://thomas-fung.github.io/mpcmp/reference/fit_glm_cmp_const_nu.md)
  and
  [`fit_glm_cmp_vary_nu()`](https://thomas-fung.github.io/mpcmp/reference/fit_glm_cmp_vary_nu.md).
- Functions such as [`print()`](https://rdrr.io/r/base/print.html),
  [`summary()`](https://rdrr.io/r/base/summary.html) are updated to
  support the updated
  [`glm.cmp()`](https://thomas-fung.github.io/mpcmp/reference/glm.cmp.md).
- Added spelltest as part of the testing procedure.
- Added the `sitophilus` dataset to demonstrate the updated
  [`glm.cmp()`](https://thomas-fung.github.io/mpcmp/reference/glm.cmp.md)
  function.

``` r

data(sitophilus)
M.sit <- glm.cmp(formula = ninsect ~ extract, formula_nu = ~extract, 
data = sitophilus)
summary(M.sit)
```

## mpcmp 0.2.0

- Added a `NEWS.md` file to track changes to the package.
- Added a draft logo to the package.
- Ribeiro Jr et al. (2018) specification of the CMP model is utilised to
  provide a better initial estimate for the dispersion parameter. Added
  `comp_mu_loglik_log_nu_only()` to facilitate the optimisation.
- [`Z()`](https://thomas-fung.github.io/mpcmp/reference/Z.md), the
  normalizing constant function, approximates its true value via (a
  fixed) truncation. This means the approximation would fail if the mean
  is large. The followings are implemented as a fix:
  - A new function
    [`logZ()`](https://thomas-fung.github.io/mpcmp/reference/logZ.md) is
    created, based on a similar function in the `cmpreg` package of
    Ribeiro Jr, Zeviani & Demétrio (2019), and will supersede
    [`Z()`](https://thomas-fung.github.io/mpcmp/reference/Z.md) due to
    its superior numerical stability.
  - A Chebyshev’s inequality type argument is now implemented to have a
    more flexible upper truncation point.

  [`glm.cmp()`](https://thomas-fung.github.io/mpcmp/reference/glm.cmp.md),
  [`dcomp()`](https://thomas-fung.github.io/mpcmp/reference/COM_Poisson_Distribution.md),
  [`pcomp()`](https://thomas-fung.github.io/mpcmp/reference/COM_Poisson_Distribution.md),
  [`qcomp()`](https://thomas-fung.github.io/mpcmp/reference/COM_Poisson_Distribution.md),
  [`rcomp()`](https://thomas-fung.github.io/mpcmp/reference/COM_Poisson_Distribution.md)
  and functions that calculate expected values are updated to take
  advantage of these changes.

``` r

sum(0:500*dcomp(0:500,100,1.2))
sum(0:500*dcomp(0:500,150,0.8))
qcomp(0.6, 150, 1.2)
```

- Added the `fish` dataset as a proof of concept that
  [`glm.cmp()`](https://thomas-fung.github.io/mpcmp/reference/glm.cmp.md)
  can handle some larger count data.

``` r

data(fish)
M.fish <- glm.cmp(species~ 1+log(area), data=fish)
max(M.fish$fitted.values)
```

- [`comp_lambdas()`](https://thomas-fung.github.io/mpcmp/reference/comp_lambdas.md)
  now has the ability to scale up & down `lambdaub` so that the correct
  $`\lambda`$s can be found even if they are outside the preset
  boundary.
